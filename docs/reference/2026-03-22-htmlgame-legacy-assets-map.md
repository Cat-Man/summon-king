## 接入建议

1. **先接 `ui/xx_1.png`、`ui/xx_2.png`**：用于首页/背包资源条，改造成本最低。
2. **再接 `bb/` 幻兽头像**：优先落在幻兽图鉴、阵容、详情页。
3. **再接 `item/` 道具图标**：优先落在背包、奖励弹窗、商城、签到。
4. `head/` 用于角色头像系统，适合后续排行榜/联盟/聊天统一接入。
5. `huodong/` 适合活动入口和福利位，不建议优先级高于核心玩法页。

## 不建议直接复用的内容

- `htmlgame/client/game.js`：旧版强耦合逻辑，不适合当前 Vue 3 + TS 架构。
- `htmlgame/client/style.css`：可参考视觉元素，但不建议整体复用样式。
- `htmlgame/server/*`：只可参考 demo 思路，不建议继承到当前 Go 后端。
