# 竞技场奖励与排行榜闭环 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让竞技场挑战从“只改连胜数”升级为“真实奖励写回成长钱包，并驱动排行榜变化”的日常支线闭环。

**Architecture:** 后端在 `arena` 模块内接入 `growth.Repository`，挑战结算时返回奖励增量与钱包快照；`ranking` 服务增加对竞技场记录的读取，把竞技场表现纳入个人榜单分数。前端继续复用现有 arena/ranking 页面，不扩新路由，只补奖励展示、资源同步、榜单高亮和回流入口。

**Tech Stack:** Go 1.22, Gin, Vue 3, TypeScript, Pinia, Vue Router, Vitest
