# 召唤之王实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 按既定详细设计文档完成《召唤之王》首发版的工程搭建、核心玩法开发、多端接入和后台能力建设，并保证可联调、可测试、可部署。

**Architecture:** 项目采用 `Vue 3 + TypeScript + Go + MySQL + Redis` 的模块化单体方案。玩家主游戏前端为 H5，微信小程序通过 `mini-shell + web-view` 承载同一套 H5，后端统一提供账号、资产、战斗、玩法、联盟、商业化与后台接口。核心约束是：所有资产变更只走 `asset` 模块，所有战斗只走 `battle` 模块，所有高价值结算都要求幂等。

**Tech Stack:** Vue 3, TypeScript, Vite, Pinia, Vant, Element Plus, Go 1.22+, Gin, GORM, MySQL 8, Redis, Asynq, Docker, Nginx, Prometheus, Grafana.

**Prerequisites:** 先阅读并冻结以下文档：
- `docs/plans/2026-03-21-召唤之王详细设计文档.md`
- `docs/plans/2026-03-21-召唤之王实施计划.md`
