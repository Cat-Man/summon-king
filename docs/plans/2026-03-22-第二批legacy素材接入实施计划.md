# 第二批 Legacy 素材接入 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将第二批 legacy 素材继续接入当前 `apps/game-web`，把联盟页补上角色头像，把签到页和商城页补上礼包/奖励图标，形成更接近实际游戏感知的前端演示面。

**Architecture:** 延续第一批的做法：所有素材统一收口到 `apps/game-web/src/assets/legacy/` 并通过 `index.ts` 暴露语义化映射；页面侧只做局部 `img` 插入与样式增强，不引入旧版 JS/CSS，不改路由和状态层。第二批重点覆盖 `head/`、`item/`、`huodong/` 三类资源，优先接入联盟成员、签到奖励和商城礼包卡。

**Tech Stack:** Vue 3, TypeScript, Vite, Vitest, @vue/test-utils.

**Prerequisites:**
- 阅读 `docs/reference/2026-03-22-htmlgame-legacy-assets-map.md`
- 参考第一批计划 `docs/plans/2026-03-22-首批legacy素材接入实施计划.md`
- 在 worktree `feat/task2-task3-foundation` 上实施
