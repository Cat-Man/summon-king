# 统一资产结算层 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 抽离统一奖励/资产结算层，让副本、塔、竞技场停止直接操作 growth 钱包仓储，而是统一经过一个后端资产服务。

**Architecture:** 新增最小 `asset` 模块，暂不暴露 HTTP，只作为后端内部服务提供 `Apply(delta)` 与 `Snapshot()`。`dungeon`、`tower`、`arena` 迁移为依赖该服务，并保持现有 API 返回结构不变，避免影响已完成的前端闭环。

**Tech Stack:** Go 1.22, Gin, 内存仓储（通过 growth.Repository 承接钱包状态）
