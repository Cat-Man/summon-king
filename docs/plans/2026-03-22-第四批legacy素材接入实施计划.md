# 第四批 Legacy 素材接入 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将第四批 legacy 素材接入 `Arena`、`AllianceWar`、`Cultivation` 三页，让竞技场、盟战和修行页面摆脱纯文本或半文本状态，形成更连续的玩法引导体验。

**Architecture:** 延续前几批做法，继续通过 `apps/game-web/src/assets/legacy/index.ts` 暴露语义化资源映射。第四批优先覆盖 `head/` 角色头像、`item/` 道具图标、`bb/` 幻兽头像和 `huodong/` 活动图标；页面只做局部卡片增强和图片节点插入，不引入旧版 JS/CSS，不改路由和数据层。

**Tech Stack:** Vue 3, TypeScript, Vite, Vitest, @vue/test-utils.

**Prerequisites:**
- 阅读 `docs/reference/2026-03-22-htmlgame-legacy-assets-map.md`
- 参考第一至第三批计划
- 在 worktree `feat/task2-task3-foundation` 上实施
