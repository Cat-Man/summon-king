# 首批 Legacy 素材接入 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将旧版 `htmlgame/client` 中首批高优先级 PNG 素材接入当前 `apps/game-web` 前端，让首页、背包、幻兽图鉴、主力阵容、幻兽详情从纯文本卡片升级为带真实游戏资源图的页面。

**Architecture:** 采用“素材文件入仓 + 共享资源注册表 + 页面局部替换”的最小改造方案。所有首批素材统一复制到 `apps/game-web/src/assets/legacy/`，再通过一个 `legacyAssets.ts` 注册表暴露给页面使用；页面仅补充 `img` 与轻量样式，不改路由、不改状态层、不引入旧版 JS/CSS。这样既能保证 Vite 正确打包，也能让后续第二批素材接入沿用同一套路径与命名约束。

**Tech Stack:** Vue 3, TypeScript, Vite, Vitest, @vue/test-utils.

**Prerequisites:**
- 阅读 `docs/reference/2026-03-22-htmlgame-legacy-assets-map.md`
- 仅复用图片素材，不复用 `htmlgame/client/game.js` 与 `style.css`
- 在 worktree `feat/task2-task3-foundation` 上实施
