# 第三批 Legacy 素材接入 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将第三批 legacy 素材继续接入当前 `apps/game-web`，补强排行榜头像展示、VIP 礼包展示和副本奖励展示，让更多核心引导页摆脱纯文本骨架。

**Architecture:** 延续前两批“共享 assets registry + 页面局部增强”的做法。优先复用已入仓的 `head/`、`item/`、`ui/`、`bb/` 素材，不引入旧版 JS/CSS，不改路由与状态层；新增的页面测试只验证真实图片节点与关键文案，保证最小实现、最小风险。

**Tech Stack:** Vue 3, TypeScript, Vite, Vitest, @vue/test-utils.

**Prerequisites:**
- 阅读 `docs/reference/2026-03-22-htmlgame-legacy-assets-map.md`
- 参考第一批与第二批计划
- 在 worktree `feat/task2-task3-foundation` 上实施
