# 首页导流与塔奖励同步 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 把首页扩成“下一步动作中枢”，并让通天塔/战灵塔挑战后的真实奖励写回成长钱包、同步到首页与塔页展示。

**Architecture:** 后端先在 `tower` 模块内接入 `growth.Repository`，用最小规则把塔奖励写回钱包，并把 `home overview` 扩成包含塔状态与推荐动作。前端继续沿用现有 overview 聚合方式，不新建中间页，只扩首页卡片和塔页结果展示，并统一改用路由跳转而不是原生 `<a>`。

**Tech Stack:** Go 1.22, Gin, Vue 3, TypeScript, Pinia, Vue Router, Vitest
