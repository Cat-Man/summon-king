# 地图组合解锁与养成导流 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 把地图副本的单一灵力门槛升级为 `spirit_power + bone_level + soul_pieces` 组合门槛，并在地图页明确告诉玩家“还差什么、该去哪里补”。

**Architecture:** 后端继续保持 `world map` 为静态地图定义，但给每个副本补齐组合门槛字段，并在 `EnterDungeon()` 时统一做组合校验。前端地图页继续同时读取地图定义和成长钱包，用同一套组合门槛字段计算锁定状态、缺口提示和推荐去向，先不引入新的玩家专属地图接口，避免在当前阶段扩大接口面。

**Tech Stack:** Go 1.22, Gin, Vue 3, TypeScript, Pinia, Vue Router, Vitest
